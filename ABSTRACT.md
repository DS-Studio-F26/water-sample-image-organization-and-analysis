# Abstract

Harmful cyanobacteria blooms threaten drinking-water supplies and recreational waters, yet monitoring relies on slow manual microscopy. In partnership with the City of Worcester and WCMC, and advised by Prof. Nathan Ahlgren, this Clark University Data Science Studio project builds the data infrastructure needed to apply machine learning to FlowCam imaging of local water samples. FlowCam, a flow-imaging microscope, produced hundreds of thousands of cropped particle images stored in inconsistently named folders, which made them difficult to search, compare, or use for model training.

We developed a Python cataloging pipeline that parsed folder names into structured metadata (site, water body type, date, magnification, dilution, and capture mode), normalized site names, preferred processed folders, and validated image readability. The resulting catalog contains 511,765 images from 613 sample folders, 45 sites, and 36 sampling dates, with no unreadable files. We then built a web application on Supabase (PostgreSQL, authentication, row-level security) and Cloudflare (Pages, Workers, R2) that lets anyone browse, filter, and download images, and lets approved labelers classify them. The labeling interface supports bulk selection, keyboard shortcuts, an image viewer, undo, progress tracking, and CSV export, while the database records who labeled each image and when. The interface was redesigned for accessibility, meeting WCAG AA contrast standards with no automated violations, and includes light and dark themes and a demonstration mode for testing without credentials. Complementary work includes a FlowCam file-format decoder and an evaluation of machine-learning models on the imagery.

Together, these components convert raw instrument output into a documented, searchable, and labelable dataset. The next steps are finalizing the label taxonomy with domain experts, deploying the labeling workflow, and using the labeled images to train and validate cyanobacteria classifiers to support faster, more consistent water-quality monitoring.
