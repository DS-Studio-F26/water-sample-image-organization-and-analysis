# Abstract
Harmful cyanobacterial blooms threaten drinking water and local water bodies, but monitoring them depends on looking at samples under a microscope by hand, which is slow. In collaboration with the City of Worcester and WCMC, and with help from Prof. Nathan Ahlgren, our project builds the tools needed to use machine learning on FlowCam images of local water samples. A FlowCam is a microscope that takes pictures of particles in flowing water. It produced hundreds of thousands of small images, saved in folders with inconsistent names, which made them hard to search, compare, or use to train a model.

First, we wrote a Python script that reads each folder name and pulls out details like the site, date, magnification, and dilution. It also fixes inconsistent site names, picks the processed version of each folder, and checks that every image opens. The final catalog has 511,765 images from 613 folders, 45 sites, and 36 sampling dates, and none were unreadable. Next, we built a website using Supabase for the database and logins and Cloudflare for hosting and image storage. Anyone can browse, filter, and download images, and approved users can label them. The labeling page supports selecting many images at once, keyboard shortcuts, undo, progress tracking, and CSV export, and the database records who labeled each image and when. We also added dark mode and a demo mode that works without an account. Teammates also built a FlowCam file decoder and tested machine learning models.

Together, these pieces turn raw FlowCam output into an organized, searchable dataset that people can label. Our next steps are to finalize the label categories with experts, launch the labeling tool, and use the labeled images to train and test models that detect cyanobacteria, making water monitoring faster and more consistent.
