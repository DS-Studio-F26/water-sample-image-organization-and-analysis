1 Datatypes in Python

1.1 Key concepts

Before starting this section let’s first learn What Mutable/Immutable means when talking about Python datatypes?

A mutable object is an object whose value or state can be changed after creation.

In other words, you can modify, add, or delete the content of mutable objects without creating a new object. Mutable objects are dynamic in nature.

An Iterable object is an object that can be looped through (like strings, lists, tuples, dictionaries, ranges, etc.). Floats and integers are not iterables. Iterables are the foundation of Python loops and many built-in functions.

2.1.1 Integers

In Python, the integer (int) data type is used to represent whole numbers, both positive and negative, without any fractional or decimal component. Integers can be of any length, limited only by the available memory in the system.

Common operations such as addition, subtraction, multiplication, and division can be performed with integers, and Python provides built-in functions like int() to convert other types (e.g., strings or floats) into integers when applicable. Additionally, integers are immutable, meaning their value cannot be changed after creation.

The float type in Python represents a floating-point number. Float values are specified using a decimal point. Floats in Python are immutable, meaning their value cannot be changed after they are created. Any operation on a float results in the creation of a new float object.

Store collections of items in a specific order. Sequence types have below characteristics:

  • Can be iterated over (supports iteration).
  • Supports indexing and slicing (e.g., my_sequence[0], my_sequence[1:3]).

  • str: Strings of text (e.g., 'Hello', "World")

2.2.2 List

A list in Python is a versatile data structure used to store an ordered collection of arbitrary objects. Lists are defined by enclosing a comma-separated sequence of objects in square brackets ([]). They are dynamic and can grow or shrink as needed. Key characteristics of lists include:

  1. Ordered: The order of elements is preserved.
  2. Arbitrary Objects: Lists can store elements of any type (e.g., integers, strings, or even other lists).
  3. Indexing and Slicing: List elements can be accessed and modified using indices and slices.
  4. Nested Lists: Lists can contain other lists as elements.
  5. Mutable: Lists can be modified after creation (e.g., elements can be added, removed, or updated).
  6. Dynamic: Lists can be modified on the fly.

Common List Operations: - Create a list: my_list = [1, 2, 3] - Access elements: my_list[0] (first element) - Modify elements: my_list[1] = 5 - Add elements: my_list.append('new') or my_list.insert(1, 'new') - Remove elements: my_list.pop() or my_list.remove(2) - Check membership: 2 in my_list # Output: True

2.2.3 Tuple

A tuple is similar to a list but is immutable, meaning its elements cannot be modified after creation. Tuples are defined by enclosing elements in parentheses (()). They are useful for representing fixed collections of items.

Key characteristics of tuples include:

  1. Ordered: The order of elements is preserved.
  2. Immutable: Tuples cannot be modified once created.
  3. Heterogeneous: Tuples can store elements of different types.
  4. Packing and Unpacking: Tuples support packing multiple elements into one object and unpacking them into individual variables.
### Common Tuple Operations
- **Create a tuple**: `my_tuple = (1, 2, 3)`
- **Access elements**: `my_tuple[0]` (first element)
- **Packing**: `t = 1, 2, 3` (equivalent to `(1, 2, 3)`)
- **Unpacking**: `a, b, c = t`
# Create a tuple
my_tuple = (1, 'hello', 3.14, True)
print(my_tuple)  # Output: (1, 'hello', 3.14, True)

# Access elements
print(my_tuple[1])  # Output: 'hello'

# Packing and Unpacking
packed_tuple = 1, 2, 3
a, b, c = packed_tuple
print(a, b, c)  # Output: 1 2 3

# Attempting to modify (immutable)
try:
    my_tuple[0] = 10
except TypeError as e:
    print(e)  # Output: 'tuple' object does not support item assignment

2.2.4 Range

A range in Python is a built-in sequence type used to generate a sequence of numbers, typically for iteration in loops. It is defined using the range() function, which can take one, two, or three arguments (start, stop, and step). Unlike lists, ranges are not mutable and are often used for their memory efficiency since they generate numbers on demand.

Key Characteristics

  • Immutable: Once created, a range object cannot be modified.
  • Lazy Evaluation: Range generates numbers only as needed, making it memory efficient.
  • Customizable: Supports specifying the start, stop, and step values.
  • Supports Iteration: Commonly used in loops and comprehensions.

Common Usage:

  • Create a range:
    • range(stop) – range(5) generates numbers from 0 to 4.
    • range(start, stop) – range(1, 5) generates 1, 2, 3, 4.
    • range(start, stop, step) – range(0, 10, 2) generates 0, 2, 4, 6, 8. (step can be increment (positive int), or decrement (negative int))
  • Access elements:
    • Convert to a list: list(range(5)) gives [0, 1, 2, 3, 4].
    • Indexing: range(5)[2] gives 2.
  • Use in loops: ```python for i in range(1, 5): print(i) # Output: 1, 2, 3, 4

2.3 Boolean Type, Boolean Context, and “Truthiness”

The Boolean type in Python represents values of True or False, which are special instances of the bool class and are often used in logical operations and conditional statements. Python uses Boolean context to evaluate the “truthiness” of objects, where non-Boolean objects are interpreted as either True or False in situations like if statements, while loops, or logical expressions. An object’s truthiness determines whether it is considered True or False when used in a Boolean context. By default, most objects are considered True, except for a few specific cases like None, False, numeric values equal to 0, empty containers (strings, lists, tuples, dictionaries, sets), and custom objects that implement the bool() or len() methods to return False.

# Boolean Type
print(bool(1))        # Output: True
print(bool(0))        # Output: False

# Boolean Context
if 42:                # 42 is truthy
    print("Truthy!")  # Output: Truthy!

if []:                # An empty list is falsy
    print("Falsy!")
else:
    print("Falsy!")   # Output: Falsy!

# Truthiness
print(bool(None))     # Output: False (None is falsy)
print(bool("Hello"))  # Output: True (non-empty string is truthy)
print(bool([]))       # Output: False (empty list is falsy)

2.5 Set Types

Characteristics of Sets 1. Unordered: Sets do not maintain the order of elements (or collection of elements). 2. Unique Elements: Duplicate elements are automatically removed. 3. Mutable: You can add or remove elements from a set, but the elements must be immutable.

Defining Sets 1. Using set() Function: - Pass an iterable (e.g., list, tuple, or string) to set() to create a set. - Example: python s = set(['a', 'b', 'c', 'a']) # Output: {'a', 'b', 'c'} 2. Using Curly Braces {}: - Add elements directly to the set. - Example: python s = {'a', 'b', 'c'} # Output: {'a', 'b', 'c'} Operations with Sets 1. Add Elements: - Use .add() to add a single element to the set. - Example: s.add('d')

  1. Remove Elements:
    • Use .remove() to remove an element.
    • Example: s.remove('b')
  2. Membership Check:
    • Use in to check if an element exists in the set.
    • Example: 'a' in s
  3. Mathematical Operations:
    • Union (|): Combines elements from two sets.
    • Intersection (&): Returns common elements.
    • Difference (-): Returns elements in one set but not the other.
    • Symmetric Difference (^): Returns elements unique to each set.

Immutable Sets - Frozenset: An immutable version of a set. - Cannot be modified after creation. - Can be used as a key in a dictionary or an element in another set.

Restrictions 1. Set elements must be immutable (e.g., integers, strings, tuples). Means Lists and dictionaries cannot be set elements because they are mutable.

3 Variable Assignment in Python

In Python, variables are references to objects, not the data itself. When you assign a value to a variable, Python creates the object and the variable points to it. Multiple variables can reference the same object, and an object’s lifetime continues as long as at least one reference exists. Once an object has no references, it is removed from memory through garbage collection.

Each object in Python has a unique identifier (accessible via id()), which ensures no two objects share the same identifier during their overlapping lifetimes. However, for optimization, Python caches small integer objects in the range [-5, 256], meaning integers within this range may share the same object.

3.1 Variable Naming Rules

  • Variable names can include letters (A-Z, a-z), digits (0-9), and underscores (_), but cannot start with a digit.

- Naming styles include:
- Camel Case: numberOfCollegeGraduates
- Pascal Case: NumberOfCollegeGraduates
- Snake Case: number_of_college_graduates (We will use this one in our class)

3.2 Important Note

  • Use descriptive variable names for readability.
  • Be cautious of variable names with differing cases (e.g., age vs. Age) to avoid confusion.

8 Namespaces and Their Role in Python

What is Namespace?

A collection of names (variables) mapped to objects, similar to a dictionary. e.g., in x = 10, x is the name of the object’s name (key) and 10 is the actual object (value).

Why is Namespacing important?

It prevents name conflicts, especially in large programs. It allows the same name to exist in different contexts without interfering with each other.

Types of Namespaces in Python:

  • Built-in Namespace:

    • Contains Python’s built-in functions and objects (like len, int, print, etc.).
    • Always available and created when Python starts (available globally).

  • Global Namespace:

    • Created for the main script or module.
    • Contains names defined at the top level of the script or module.

  • Local Namespace:

    • Created inside a function or method.
    • Contains names defined in that specific function.
    • Exists only during the function’s execution.

  • Enclosing Namespace:

    • Appears in nested functions.
    • Refers to the namespace of the outer (enclosing) function.

LEGB Rule

When resolving variable names, Python searches through namespaces in the following order:

  • Local
  • Enclosing
  • Global
  • Built-in
# Global Namespace
global_var = "I am global"

def outer_function():
    # Enclosing Namespace
    enclosing_var = "I am enclosing"
    
    def inner_function():
        # Local Namespace
        local_var = "I am local"
        
        # Accessing Built-in Namespace
        print("Built-in:", len(local_var))  # `len` is from the built-in namespace
        
        # Accessing Local Namespace
        print("Local:", local_var)
        
        # Accessing Enclosing Namespace
        print("Enclosing:", enclosing_var)
        
        # Accessing Global Namespace
        print("Global:", global_var)
    
    inner_function()
