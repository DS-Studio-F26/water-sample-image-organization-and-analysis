Exploring Transposed Convolutions and Unpooling

Let’s examine how transposed convolutions and unpooling works using PyTorch functions with the image we downloaded in Assignment 2.

import numpy as np
import torch
from torch import nn
from torch.nn import functional as F
from scipy import sparse
from PIL import Image
import requests
import torchvision.transforms as transforms
import matplotlib.pyplot as plt

Transposed Convolutions

We have already seen in the section on Semantic Segmentation how transposed convolutions function as matrix multiplications. Now let’s explore them on an image. To do so, we will first set up a function that transforms an image to a torch.Tensor after resizing it. We’ll also define a function that can be used to downsample an image several times, by passing an image through a series of nn.MaxPool2d operations.

def transform(image, h, w, c):
    if h == w:
        dims = h
    else:
        dims = (h, w)
    transformed = transforms.Compose([
        transforms.Resize(dims),
        transforms.ToTensor()
    ])
    transformed = transformed(image)[c]

    return transformed

def pooler(image, n):
    pool = nn.MaxPool2d(2, stride=2, padding=0, return_indices=True)
    pooled = []
    for i in range(n):
        if i == 0:
            pooled.append(pool(image))
        else:
            pooled.append(pool(pooled[i-1][0]))
    return pooled

Upsample back to original size

Let’s return each of those downsampled images back to their original resolution. Let’s first set up a function transconv that will run a transposed convolution, using a provided kernel (served as a matrix), a given stride, and padding. We’ll provide a second function for plotting the upsampled images along with the pooled images.

def transconv(image, k, f, s, p):
    f = int(len(k)**(1/2))  # kernel size
    tconv = nn.ConvTranspose2d(in_channels=1, out_channels=1, kernel_size=f,
                               stride=s, padding=p, bias=False)

    K = torch.Tensor(k).reshape(f,f) / np.sum(k)
    tconv.weight.data = K.unsqueeze(0).unsqueeze(0)

    Z = tconv(image).detach()

    return Z

def upsample_plots(inlist, n):
    fig, (axs1, axs2) = plt.subplots(2, n, figsize=(15, 6))
    for i in range(0,n):
        ul = inlist[i]
        ph = ul['pool'].shape[1]
        uh = ul['up'].shape[1]
        axs1[i].imshow(ul["up"][0].numpy(), cmap="gray")
        axs1[i].set_title(f"Up to {uh}x{uh}")
        axs2[i].imshow(ul["pool"][0].numpy(), cmap="gray")
        axs2[i].set_title(f"Pooled {ph}x{ph}")

We will use a simple kernel that will do bilinear interpolation during up-sampling (adapted from here, since we are not learning weights. Below we define a kernel as a simple list, but we break lines so we can what it looks like when it is square. transconv converts it to the necessary kernel.

k = [1, 2, 2, 1,
     2, 4, 4, 2,
     2, 4, 4, 2,
     1, 2, 2, 1]

So we now have a 4x4 kernel that we will use to upsample the images in pooled_list, each of them by a factor of 2. We want the 7x7 to be upsampled to 14x14, the 14x14 to 28x28, etc. We are not going to keep upsampling the same image in reverse, but rather show the averaging the upsampling from the image just one level below the target resolution. We’ll keep the corresponding pooled along with the 2X upsampled image in the output for plotting purposes.

But before running that, let’s first check that our parameters for running the transposed convolution will get us to the right shape. Remember the formula:

\[ o = (i-1) \cdot s + f-2 \cdot p \]

Where \(o\) is the output dimension, \(i\) is the input dimension, \(s\) is stride, \(f\) is the kernel dimension, and \(p\) is padding. Given, let’s see what a 7x7 becomes with a 4x4 kernel a stride of 2, and padding of 1.

i = 7
s = 2
f = 4
p = 1
(i - 1) * s + f - 2 * p

We get 14x14. We can also get 14X14 by removing padding and setting the kernel to 2x2 and keeping stride at 2.

i = 7
s = 2
f = 2
p = 0
(i - 1) * s + f - 2 * p

Let’s run this now, keeping kernel of 4 and padding of 1.

up_list1 = [

We’ll try one more approach, where go all the way from bottom 7x7 to the top by upsampling, then averaging with the layer above.

# Add original image to list of pooled images
image_list = pooled_list.copy()
image_list.insert(0, imgt.reshape(1, 224, 224))
image_list.reverse()

# Upsample the layer below and average it with the layer above
up_merge = []
for i in range(0, 5):
    if i == 0:
        up = transconv(image_list[i][0], k=k, f=4, s=2, p=1)
    else:
        up = transconv(up_merge[i-1], k=k, f=4, s=2, p=1)

    up_merge.append((up + image_list[i+1][0]) / 2)
fig, axs = plt.subplots(1, 5, figsize=(15, 5))
for i in range(0,5):
    um = up_merge[i][0].numpy()
    axs[i].imshow(um, cmap="gray")
    axs[i].set_title(f"Up and average w/{um.shape[1]}x{um.shape[1]}")

You can see the result looks very similar to the original pooled images at the same output size. This upsample and combine with the pooled layer above is somewhat analogous to what U-Net does, although here we are averaging, not concatenating, nor following the concatenation with two convolutional layers.

Unpooling

We’ll wrap up by looking at how max unpooling, which is used in SegNet and DeConvNet, works.

We’ll start by defining two functions. One that does the unpooling, taking a list with two elements: 1) a pooled image, 2) and the indices of the pixels selected during the max pooling operation that made the pooled image.

The second runs two sequential 3x3 convolutions over the unpooled output of the first function, using a provided kernel

def unpooler(pooled):
    unpool = nn.MaxUnpool2d(kernel_size=2, stride=2)
    return unpool(pooled[0], pooled[1])[0]

def double_conv(unpooled, k):
    conv = nn.Conv2d(in_channels=1, out_channels=1, padding=1,
                     kernel_size=3, stride=1, bias=False)
    conv.weight.data = k.unsqueeze(0).unsqueeze(0)

    conv1 = conv(unpooled.unsqueeze(0))
    return conv(conv1).detach()

We’ll define a kernel with equal weights to give to double_conv.

k = [1, 1, 1,
     1, 1, 1,
     1, 1, 1]
k = torch.Tensor(k).reshape(3,3)
k = k / sum(k)

And then loop over image_list (dropping the last element, which contains the original input image), unpooling and running the double_conv

fig, (axs1, axs2) = plt.subplots(2, 5, figsize=(15, 6))
for i in range(5):
    unpooled = unpooler(image_list[:-1].copy()[i])
    convs = double_conv(unpooled, k)
    axs1[i].imshow(unpooled.numpy(), cmap="gray")
    axs1[i].set_title(f"Unpooled {unpooled.shape[0]} x {unpooled.shape[0]}")
    axs2[i].imshow(convs.numpy()[0], cmap="gray")
    axs2[i].set_title(f"Double Conv")

Our kernel doesn’t quite the detail back that we would like, but these are just naive filters, and only one each.
